# Currículo online

Página pessoal em formato de currículo, com seções de Sobre, Educação, Habilidades e Interesses e menu lateral de navegação.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Bootstrap

## Como executar

```bash
git clone https://github.com/peluca2007/Curricolo.git
cd Curricolo
```

Abra o `index.html` no navegador.
